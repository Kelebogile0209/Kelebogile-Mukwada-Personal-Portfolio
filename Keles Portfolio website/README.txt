KELEBOGILE MODERN PORTFOLIO
============================

Files:
- index.html       -> Home page
- about.html       -> About page
- projects.html    -> Skills, projects and learning resources
- contact.html     -> Contact page
- style.css        -> All styling and responsive design
- script.js        -> Dark mode, mobile menu, animations, filtering and form interaction

HOW TO RUN:
1. Put all files in the same folder.
2. Double-click index.html, or open it with VS Code and use Live Server.
3. Add your own photo and name it:
   BlazerSelfie.jpeg
   Then place it in the same folder as the HTML files.
4. Replace the placeholder email and LinkedIn details in contact.html.

IMPORTANT:
The original uploaded portfolio was used as the content foundation. The redesign keeps
the original themes: Computer Science studies, skills, online learning platforms,
self-development, gym/dancing interests and contact section, while reorganizing them
into a modern multi-page portfolio.

The contact form is currently a front-end demo. It does not send email until you connect
it to a backend or a form service.
